## 🚀 النشر على VPS والربط عبر Coolify

المشروع مُهيأ بالكامل للنشر الفوري والمباشر على أي خادم **VPS** يتم إدارته عبر لوحة **Coolify**.

### الطريقة الأولى: النشر التلقائي عبر Coolify (الأسهل والأسرع)

1. ادخل إلى لوحة تحكم **Coolify** الخاصة بك.
2. اذهب إلى **Projects** ثم اختر مشروعك أو اضغط **+ New Project**.
3. اضغط **+ New Resource** ثم اختر **Git Source** -> **GitHub**.
4. اختر المستودع: `Hazemabouseafa/FastPage-Eldefaa` (الفرع `main`).
5. في نوع البناء (Build Pack):
   - اختر **Dockerfile** (سيتعرف Coolify تلقائياً على ملف `Dockerfile` المدمج مع خادم Nginx السريع والمحصن).
   - أو اختر **Static** وحدد المجلد الجذر.
6. في خانة **Domains**: اكتب اسم الدومين الخاص بك (مثال: `https://eldefaa.com`). سيقوم Coolify تلقائياً بإصدار شهادة SSL (HTTPS) مجانية من Let's Encrypt.
7. اضغط على زر **Deploy**. في غضون 10 ثوانٍ، سيكون الموقع متاحاً ويعمل بكفاءة فائقة!

---

### الطريقة الثانية: التشغيل المباشر عبر Docker Compose على السيرفر

إذا كنت ترغب في تشغيله يدوياً عبر الـ Terminal داخل الـ VPS:

```bash
# استنساخ المستودع
git clone https://github.com/Hazemabouseafa/FastPage-Eldefaa.git
cd FastPage-Eldefaa

# بناء وتشغيل الحاوية في الخلفية
docker compose up -d --build
```

سيعمل الموقع تلقائياً على المنفذ `80`.
